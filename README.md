# Online Quiz Management System

A Java-based console application for managing and attempting online quizzes.

## Features

- Student registration and login
- Admin login
- Quiz listing
- Multiple-choice questions
- Timed quiz using multithreading
- Automatic score calculation
- Result history
- Leaderboard
- Exception handling
- Object-oriented design

## Technologies

- Java
- Java Collections Framework
- Java Threads
- File/console I/O
- Git/GitHub

## Project Structure

- `model` - application data classes
- `service` - business logic
- `util` - utility classes such as the timer
- `Main.java` - application entry point

## How to Run

1. Install JDK 17 or later.
2. Open the project in IntelliJ IDEA, Eclipse, or VS Code.
3. Mark `src` as the source folder if required.
4. Run `Main.java`.
