# Project Statement

## Problem Statement

Traditional quiz systems often require manual question distribution, checking, and result calculation. This project provides a simple digital quiz management system that allows students to register, log in, attempt quizzes, receive automatic scores, and view their results.

## Scope

The system focuses on quiz management, student interaction, timed assessments, automatic evaluation, result tracking, and leaderboard display.

## Target Users

- Students who want to attempt quizzes.
- Administrators who need to view available quizzes and performance information.

## High-Level Features

1. User registration and authentication.
2. Quiz and question management structure.
3. Timed quiz execution.
4. Automatic score calculation.
5. Result history.
6. Leaderboard.
7. Exception and input validation.

## Java Concepts Used

- Classes and objects
- Encapsulation
- Inheritance
- Polymorphism
- Collections
- Exception handling
- Multithreading
